# Controls

Minecraft Web Clone — **V25.39**  
In-game version: **Beta Survival 15.2 - Sheep BOOT FIX**

## Movement

| Control | Action |
|---|---|
| `W` | Move forward |
| `S` | Move backward |
| `A` | Move left |
| `D` | Move right |
| Mouse | Look around |
| Arrow keys | Look around (alternative) |
| `Space` | Jump |
| Hold `Space` in water | Swim upward |
| `Left Shift` | Sneak |
| `Ctrl` + `W` | Sprint |
| `Z` | Zoom |

## Mouse

| Control | Action |
|---|---|
| Left click | Break block / attack mob |
| Right click | Place or use item / interact |
| Middle click | Pick targeted block in Creative |
| Mouse wheel | Change hotbar slot |

## Inventory

| Control | Action |
|---|---|
| `E` | Open/close inventory |
| `1`–`9` | Select hotbar slot |
| `Shift` + Left click | Quick move items / quick craft where supported |
| Left / Right drag | Distribute held items through inventory slots |
| Triple Left click | Consolidate matching items into the clicked stack |

## Survival-only

| Control | Action |
|---|---|
| `Q` | Drop one selected item |
| `Ctrl` + `Q` | Drop the whole selected stack |
| Hold Left click | Mine blocks |
| Right click | Place/use item, eat food, open chest/furnace/crafting table, use doors/beds |

## Creative-only

| Control | Action |
|---|---|
| Double-tap `Space` | Toggle flying |
| `Space` while flying | Fly upward |
| `Shift` while flying | Fly downward |
| `X` | Toggle X-Ray |
| `B` | Toggle Super Breaker |
| `L` | Toggle Spectator mode |
| `Enter` | Cycle block shape: Cube → Slab → Stair |
| `Ctrl` + Left click | Place selected block |
| Mouse wheel in Creative inventory | Scroll item catalog |

## Other

| Control | Action |
|---|---|
| `P` | Pause / resume |
| `Esc` | Release mouse / close the current game menu |
| `F11` | Fullscreen |
| `Ctrl` + `F` | Fullscreen alternative |

> Note: browser or operating-system shortcuts can sometimes intercept keys before the game receives them.
